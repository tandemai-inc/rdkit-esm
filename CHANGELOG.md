# Changelog

## [vX.X.X] Unreleased

## [v0.9.0]

- Upgrade minimalLib to RDKit v2026.09.3 (SHA 2b54009e0b381fa12447402412dd0701d16f8138)
- `Mol.minimize()` accepts `positionRestraints`: groups of atoms tethered to their starting coordinates by a flat-bottomed harmonic restraint (`maxDisplacement`, `forceConstant`), unlike `fixedAtoms` which freezes them

## [v0.8.0]

- Upgrade minimalLib to RDKit v2026.09.1 (SHA fece8caa860bdf6c9c82bdb9253f22a0cf87150c)
- Reduce WASM size from 9.0 MB to 7.1 MB: drop the unexposed ETKDGv4 torsion tables and RDKit default ring templates, deduplicate header-defined string tables (`wasm/patches/0002`–`0004`)
- `Mol.getSubstructMatch()` / `Mol.getSubstructMatches()` accept `RDKitSubstructMatchOptions` (e.g. `uniquify`, `maxMatches`, `useChirality`); add the matching `details` overloads to the MinimalLib typings

## [v0.7.0]

- MinimalLib WASM now includes minimization and conformer generation
- RDKit upgraded to v2026.09 preprelease SHA 23378a7f2f82ae6c867201db8c56ab4cc4a4e671
- Add `Mol.getForceFieldEnergy()`, `Mol.minimize()` (MMFF94 with UFF fallback) and `Mol.generateConformers()` (ETKDGv3)
- Add `RDKitOperationError` / `isRDKitOperationError`; the error listener also reports failures of these `Mol` operations
- Upgrade minimalLib to RDKit v2026.03.1
- fix type guards for null return type
- remove isValid and mark is_valid() as deprecated in minimalLib types
- add getSVGWithDrawCoords to handle inconsistent return type when `returnDrawCoords` is true

## [v0.6.0]

- Add Dice, Cosine, Tversky and Asymmetric FP similarity
- Implement Substructure Library: `RDKit.createSubstructLibrary()`, fix types
- Implement MMPA fragmentation: `Mol.getMmpaFrags()`
- Port tests from rdkit minimalib tests.js
- Missing types: colour palette presets, Drawing extents, highlightAtomRadii, sanitize flags, assignCIPLabels, setAromaticBonds, strictValenceCheck, parseProperties, parseConformers, get_frags options
- Missing parameters: `rdkit.molzip()`, `Mol.getFrags()`

## [v0.5.1]

- bump dependencies
- static name export `RDKit_minimal.wasm` wasm binary to allow usage in third party bundlers
- disable autogenerated `exports` in tsdown config. Fixes wasm bundling for workers

## [v0.5.0]

- errors interception: console.log `configure({ enableLogging: bool })`, event listener `addErrorListener(cb: (e: Error))`, throwOnError opt-in
- condenseAbbreviations returns a substructure match
- add `numHeavyAtoms` getter and `getCoords()` to Mol class
- add `delete()` to returned objects containing reference to WASM instances
- add `configure()` to main rdkit class for coordgen/legacy stereo/non tetrahedral stereo settings

## [v0.4.3]

- RDKit minimalib typings feature complete
- Export types for CommonChem entities (RDKitJsonAtoms, etc...)

## [v0.4.2]

- fix: configure module build for browser (was neutral). Fixes bundling by third parties for browsers.

## [v0.4.1]

- fix: fingerprint text output

## [v0.4.0]
